安装

预编译包发布在 GitHub Releases：

目标 包 依赖
macOS Apple Silicon muxterm-macos-arm64.dmg macOS 13+
Linux x86_64 muxterm-gtk-linux-x86_64.tar.gz GTK4、vte4、OpenSSL、tmux 3.x

macOS 包使用 ad-hoc 签名，未经过 Apple 公证；首次启动若被 Gatekeeper 拦截，请在系统设置中允许。

快速开始

用 muxterm gui 启动桌面 GUI，或用 muxterm tui 启动终端界面。Linux 按 Alt+P，macOS 按 Cmd+P 打开 QuickConnect。

已有的 tmux 会话、Herdr workspace、Project 与 worktree 都会出现在候选列表里；切换已打开的工作区没有 Core 锁等待。

工作区工作台

tmux 与 Herdr 不是被套进一个假终端，而是各自进入 WorkspacePool：

Workspace = Runtime(Transport) + path
  Runtime:   shell / tmux / herdr
  Transport: local / ssh
  结构:      Tab → Pane

控制 lane: 拓扑与常驻原生场景
渲染 lane: 原始 PTY 字节直达原生 Surface
Activity lane: Agent、命令与 Attention

端口感知与转发

对于 SSH 工作区，Muxterm 通过现有 SSH 连接扫描目标机上的 TCP 监听端口。macOS 状态栏会列出发现的端口，并支持：

  • 把远端端口转发到本地端口；
  • 显式开启转发端口的 LAN 访问；
  • 打开本地 / 远端地址、忽略端口或停止转发。

扫描使用目标机的 ss 或 lsof，且不在前端线程执行。Core/FFI 已提供接口；当前端口选择器 UI 在 macOS 前端。

配置契约

配置位于 ~/.config/muxterm/config.toml，严格校验 schema：

config_version = 1

[font]
family = "JetBrains Mono"
size = 13.0

[statusbar]
mode = "tmux"

[pool]
max_slots = 20

[theme]
name = "system"
light = "white"
dark = "black"

[shortcuts]
preset = "qwerty"
primary_key = "auto" # Linux=Alt，macOS=Command

[[projects]]
id = "muxterm@local"
name = "Muxterm"
path = "~/Developer/self/muxterm"

CLI 参考

不启动 GUI 也能使用：

# 列出工作区
muxterm list-workspaces

# 隔离 tmux socket
muxterm -L muxterm-test list-workspaces

# 向当前 Pane 发送按键
muxterm send-keys "cargo test"

# 检查配置
muxterm config show --resolved
muxterm config doctor

从源码构建

构建脚本把产物写入 ./build/<os>/：

git clone https://github.com/wlingze/muxterm.git
cd muxterm
./scripts/build-tui.sh --release
./scripts/build-linux.sh --release
./scripts/build-macos.sh --release
