# Bundled fonts

JetBrains Mono supplies the terminal's primary monospace face (`OFL.txt`).

Noto Sans Symbols2 supplies missing terminal symbols, including U+2800–U+28FF
Braille patterns used by animated prompts. It is registered only in the app's
Fontconfig instance; no system font or user configuration is modified.

- Upstream: https://github.com/notofonts/noto-fonts
- File: `hinted/ttf/NotoSansSymbols2/NotoSansSymbols2-Regular.ttf`
- License: `Noto-OFL.txt` (SIL Open Font License 1.1, unmodified upstream font)
